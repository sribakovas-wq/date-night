# Pasimatymo staigmena ❤️

Statinė svetainė, paruošta GitHub Pages.

## Kaip paleisti per GitHub Pages
1. Sukurk naują GitHub repository (pvz. `pasimatymas`).
2. Įkelk **visus šio aplanko failus**, išlaikydamas `images` aplanką.
3. GitHub repository atsidaryk **Settings → Pages**.
4. Prie **Build and deployment** pasirink **Deploy from a branch**.
5. Branch pasirink `main`, aplanką `/ (root)`, spausk **Save**.
6. Po kelių minučių GitHub parodys viešą svetainės nuorodą.

Tekstus galima keisti `script.js` faile, masyve `slides`. Finalinė žinutė yra `index.html` faile.
